# 활동 기록을 구글 스프레드시트로 받는 설정

학생이 5단계에서 **📤 활동 기록 제출하기**를 누르면, 학번·이름과 모든 문항의 응답이 선생님 구글 드라이브의 스프레드시트에 한 줄씩 쌓입니다. 처음 한 번만 아래 순서대로 설정하면 됩니다(약 10분).

## 1. 스프레드시트 만들기

1. [Google 스프레드시트](https://sheets.google.com)에서 **빈 스프레드시트**를 새로 만듭니다.
2. 이름을 정합니다. 예) `포트폴리오 응용 활동 기록 (3학년)`

## 2. Apps Script 붙여 넣기

1. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 저장소의 [apps-script/Code.gs](../apps-script/Code.gs) 내용을 그대로 붙여 넣습니다.
3. 위쪽의 `const CLASS_CODE = "";` 따옴표 안에 **수업 코드**를 정해 넣습니다. 예) `const CLASS_CODE = "봄비42";`
   - 학생은 제출할 때 이 코드를 함께 입력해야 하며, 틀리면 시트에 기록되지 않습니다(대소문자·앞뒤 공백은 구분하지 않음).
   - 코드는 **수업 시간에 칠판으로만** 알려 주세요. 이 Apps Script 안에만 있어서 학생 앱 코드나 GitHub에서는 보이지 않습니다.
   - 저장소의 `apps-script/Code.gs`에는 코드를 적지 마세요(공개 저장소입니다).
4. 💾 저장(Ctrl+S)합니다.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. ⚙️(유형 선택)에서 **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 설명: `활동 기록 수신`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 권한 요청이 나오면 선생님 계정으로 **허용**합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 선생님이 직접 만든 스크립트라 나오는 안내입니다.
5. 나타난 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 학교 Google Workspace 계정에서 "모든 사용자"가 보이지 않으면 관리자가 외부 공유를 막아 둔 것입니다. 개인 Gmail 계정으로 만든 스프레드시트를 쓰거나, 학교 정보 담당 선생님께 문의하세요.

## 4. 앱에 주소 넣기

1. [js/data.js](../js/data.js) 맨 위의 `SUBMIT_URL`에 복사한 주소를 넣습니다.
   ```js
   const SUBMIT_URL = "https://script.google.com/macros/s/………/exec";
   ```
2. 커밋하고 푸시하면 1~2분 뒤 학생 링크에 반영됩니다(또는 Claude에게 "제출 주소 넣고 푸시해줘"라고 요청).

## 5. 확인하기

1. 복사한 웹 앱 URL을 브라우저 주소창에 열면 `{"ok":true,"message":"활동 기록 수신 준비 완료"}`가 보여야 합니다.
2. 학생 링크에서 테스트 학번·이름으로 제출해 보고, 스프레드시트에 **제출** 시트와 **문항설명** 시트가 생기는지 확인합니다.
3. 테스트 줄은 지워도 됩니다.

## 결과 보는 법

| 시트 | 내용 |
|---|---|
| 제출 | 한 줄 = 학생 한 명의 제출 한 번. 제출 시각·학번·이름·요약, 이후 열마다 문항별 응답(정답 여부 ✓/✗ 포함) |
| 문항설명 | 각 열의 문항이 무엇을 물었는지, 의미, 평가 요소, 정답·기준 |

- 같은 학생이 다시 제출하면 **새 줄로 추가**됩니다. 제출 시각으로 마지막 제출을 확인하세요.
- 필터(데이터 → 필터 만들기)로 학번별로 보거나 정렬할 수 있습니다.

## 알아 둘 점

- **개인정보**: 학번·이름과 서술형 응답이 선생님 구글 계정에 저장됩니다. 학교의 개인정보 처리 기준에 맞게 보관하고, 학기가 끝나면 정리하세요.
- **수업 코드 바꾸기**: 반이나 차시마다 코드를 바꾸고 싶으면 Apps Script에서 `CLASS_CODE`를 고친 뒤 **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 하세요(주소는 그대로). 수업이 끝난 뒤 코드를 바꿔 두면 이후 장난 제출도 막힙니다.
- **주소 관리**: 웹 앱 주소는 학생 앱 코드에 들어 있어 찾을 수 있지만, 수업 코드를 모르면 기록되지 않습니다. 시트를 읽거나 고칠 수는 없습니다.
- **문항을 바꿨을 때**: `js/data.js`의 문항 구성을 바꾸면 기존 시트의 열 제목과 맞지 않습니다. 새 스프레드시트를 만들거나, **제출**·**문항설명** 시트 이름을 바꿔 두면 다음 제출 때 새로 만들어집니다.
- **Apps Script 코드를 고쳤을 때**: **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 해야 반영됩니다(주소는 그대로).
- **제출이 안 될 때**: 학생 화면에 "파일로 내려받기" 버튼이 나타나므로, 그 파일을 받아 두면 기록이 사라지지 않습니다.
