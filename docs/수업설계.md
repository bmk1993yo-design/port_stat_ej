# 수업 설계: 계란을 한 바구니에 담지 마라

- **대상**: 중학교 3학년 (통계 — 산포도, 산점도와 상관관계 첫 도입)
- **차시**: 2차시(45분 × 2) 권장 — 1차시: 0~2단계 / 2차시: 3~5단계
- **준비물**: 학생 1인 1기기(크롬북·태블릿) 또는 모둠별 1대, 계산기
- **실행**: `index.html`을 브라우저로 열기 (인터넷 불필요)

## 핵심 아이디어

포트폴리오 이론(마코위츠, 1952)의 예시를 중학생 눈높이로 옮긴다.

| 원문 | 수업 |
|---|---|
| A주식 (호황 18%, 보통 5%, 불황 −8%) | 🍦 아이스크림 가게 (무더운 해 / 보통 / 비 많은 해) |
| B주식 (호황 −20%, 보통 3%, 불황 20%) | ☂️ 우산 가게 |
| 위험 = 수익률의 변동성 | 표준편차 = "얼마나 들쭉날쭉한가" |
| 공분산·상관계수 | 산점도의 모양 (양/음/없음) |
| A 75% + B 25% → 표준편차 3.9% | 섞어 담기 슬라이더 |

**결정적 장면**: "평균도 낮고 위험도 큰 B를 섞었는데 오히려 위험이 줄어든다!" — 인지 갈등으로 상관관계 학습 동기를 만든다.

## 단계별 흐름

| 단계 | 시간 | 활동 | 학습 요소 | 정답·기준 |
|---|---|---|---|---|
| 0. 이야기 | 5분 | 어디에 투자할까? 투표 + 이유 쓰기 | 문제 상황 | 정답 없음, 사전 생각 기록 |
| 1. 평균과 편차 | 15분 | 평균·편차 직접 입력, 수직선 시각화 | 편차 = 변량 − 평균, 편차의 합 = 0 | A: 평균 5, 편차 13·0·−13 / B: 평균 1, 편차 −21·2·19 |
| 2. 분산·표준편차 | 20분 | 편차² 입력, 정사각형 넓이로 시각화 | 분산, 표준편차, "위험"의 의미 | A: 분산 112.7, 표준편차 10.6 / B: 분산 268.7, 표준편차 16.4 |
| 3. 산점도·상관 | 15분 | A–B 산점도 판정, 실험실에서 점 찍기 | 양·음의 상관, 상관없음 | A–B는 음의 상관 |
| 4. 섞어 담기 | 20분 | 비율 슬라이더 모둠 미션 | 상관관계 ↔ 위험 감소 연결 | 75:25 → 평균 4%, 표준편차 3.9% |
| 5. 정리 | 10분 | 퀴즈 5문항, 출구 카드, 기록 저장 | 형성평가 | 출구 카드 루브릭 아래 |

## 발문 예시

- (1단계) "편차를 다 더하면 0이 되네요. 그럼 '흩어진 정도'는 어떻게 재야 할까요?"
- (2단계) "표준편차가 크다는 건 투자자에게 어떤 의미일까요?"
- (3단계) "산점도 점들이 오른쪽 아래로 향하면 두 가게는 어떤 사이일까요?"
- (4단계) "팥빙수 가게와 섞으면 왜 위험이 별로 안 줄어들까요?"
- (마무리) "그럼 가게를 100개로 나누면 위험이 0이 될까요?" → 모두에게 영향을 주는 위험(경기 전체)은 남는다.

## 오개념 체크

- 표준편차가 크다 = 수익이 나쁘다 ✗ → **예측하기 어렵다**
- 상관관계 = 인과관계 ✗ → 신발 크기 vs 수학 점수 예시로 확인
- 위험한 자산을 더하면 무조건 위험이 커진다 ✗ → 4단계에서 반박

## 출구 카드 루브릭

| 수준 | 기준 |
|---|---|
| 상 | 표준편차(위험)와 음의 상관관계를 모두 사용해, 반대로 움직이는 자산을 섞으면 수익이 덜 들쭉날쭉해진다고 설명 |
| 중 | 두 용어 중 하나만 정확히 사용 |
| 하 | "나눠 담으면 안전하다" 수준의 일상적 설명 |

## 앱 구조

```
index.html        단계별 화면(섹션 0~5)
css/style.css     스타일
js/data.js        가게 수익률, 산점도 예시, 퀴즈 ← 교사가 수정하기 쉬운 곳
js/stats.js       평균·편차·분산·표준편차·상관계수·섞기 계산
js/charts.js      canvas 차트(수직선, 편차 정사각형, 산점도, 막대, 위험 곡선)
js/app.js         화면 전환, 입력 채점, 활동 연결, 기록 저장
```

- 날씨/가게 숫자를 바꾸고 싶으면 `js/data.js`만 고치면 모든 화면이 자동 반영된다.
- 상관계수 r은 교육과정 밖이므로 숫자 대신 **상관 미터(바늘)** 로만 보여 준다.
- 학생 기록은 서버에 저장되지 않으며, "활동 기록 저장" 버튼으로 텍스트 파일을 내려받아 제출한다.
